# LULER v6.0.0 · Explainable safety score

Built 2026-11-15 06:31 UTC.

Rule-based safety score (0-100) with 'Why this score' breakdowns, hazard layer on the terrain, three-site comparison cards, landing verdict, SpecularButton actions, checklist features.

This is the actual compiled website as it was at this milestone (index.html + assets/index-CstwgMZm.js), packaged with the NASA site data, textures and 3D models it loads. The source code for every feature is on the `main` branch (v7.0.0 and later).

## Run it

```bash
git checkout v6.0.0
python3 -m http.server 8080   # then open http://localhost:8080
```
