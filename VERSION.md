# LULER v1.0.0 · First web app

Built 2026-11-14 20:34 UTC.

Data engine output on the web: 3D Moon globe with landing and candidate sites, flat map, site terrain in 3D, surface walk mode, sunlight and Earth-visibility timelines, calendar of the best dates.

This is the actual compiled website as it was at this milestone (index.html + assets/index-BxIZCraY.js), packaged with the NASA site data, textures and 3D models it loads. The source code for every feature is on the `main` branch (v7.0.0 and later).

## Run it

```bash
git checkout v1.0.0
python3 -m http.server 8080   # then open http://localhost:8080
```
