# LULER v3.0.0 · Mission from launch to landing

Built 2026-11-15 03:29 UTC.

Saturn V from NASA 3D Resources split into real stages (S-IC, S-II, S-IVB, SLA panels, LES); launch and landing in one tab with controllable stages; mission timeline of all landing sites.

This is the actual compiled website as it was at this milestone (index.html + assets/index-pxjJhpIC.js), packaged with the NASA site data, textures and 3D models it loads. The source code for every feature is on the `main` branch (v7.0.0 and later).

## Run it

```bash
git checkout v3.0.0
python3 -m http.server 8080   # then open http://localhost:8080
```
